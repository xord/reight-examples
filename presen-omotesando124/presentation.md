# ここからは Textbringer の presentation モードで

# TerminalView の組み込み

- ゲームエンジンも GUI ライブラリー上で動いているため

- TerminalView がそのままプレゼンに組み込めました

# TerminalView の使い所 (1)

- ターミナルアプリが簡単につくれる

  - 自分好みのターミナルを自作

  - 複数タブ対応ターミナルとか（よくある）

# TerminalView の使い所 (2)

- ターミナル機能の組み込み

  - ゲームエンジンのログ表示

  - エスケープシーケンス込みで表示できる

# TerminalView の使い所 (3)

- 各プラットフォーム向けのネイティブアプリ化

  - Mac: Textbringer.app

  - Windows: Textbringer.exe

# TerminalView の特徴

- Ruby の GUI ツールキットで部品として利用可能
  - 単にターミナル1枚表示するだけのウィンドウ
　　表示するなら10行程度

- 描画速度はほどほど
  - 端末内の全文字をループして描画する部分だけは
　　C++ で高速化
  - ただ、ベースにした Ghostty ほどは速くない

- 日本語入力がまだできない
　→ → 近いうちに対応予定

# 自作のすすめ

- TernminalView でターミナルは簡単に作れるように
